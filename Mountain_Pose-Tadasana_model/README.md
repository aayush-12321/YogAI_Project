# Samasthiti (Basic Mountain Pose)
**Tadasana (Mountain Pose) have several variations. The one used in this projecct is Samasthiti (Basic Mountain Pose)**

- Feet together or slightly apart

- Arms relaxed by the sides

- Palms facing inward

- Focus on posture and balance

✔️ This is the most basic and commonly taught form.
